TEMPLATE ULANG TAHUN CINEMATIC DITAA ❤️

Foto yang kamu kirim sudah dipasang ke template.
- foto-utama.jpg = foto utama/opening & ending
- foto1.jpg sampai foto4.jpg = galeri

Karena baru 3 foto yang dikirim, beberapa slot galeri sementara memakai ulang foto yang sama.
Kalau nanti kamu kirim foto tambahan, slot tersebut bisa diganti.

MUSIK:
Masukkan file MP3 kamu sebagai:
music/lagu.mp3

PENGATURAN:
- Nama: Ditaa
- Tema: full merah maroon
- Password pesan rahasia default: 143
- Tanggal mulai hubungan dapat diubah di script.js pada bagian startDate.

GITHUB PAGES:
1. Upload isi folder ini ke repository GitHub.
2. Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /root.
5. Save.
6. Link akan menjadi https://USERNAME.github.io/NAMA-REPOSITORY/

Tidak membutuhkan Vercel.
